# Nathalie Jane M. Francisco — Portfolio

Clean, modern personal portfolio inspired by contemporary student/developer portfolios.

## Quick Start (Local)

1. Open the folder in any browser, or use a simple local server:
   ```bash
   npx serve .
   ```
2. Or just double-click `index.html`.

## Deploy to Vercel (Recommended)

### Option A — GitHub + Vercel (best long-term)

1. Create a new GitHub repository (e.g. `my-portfolio`).
2. Upload all files in this folder to the repository.
3. Go to [vercel.com](https://vercel.com) → Sign in with GitHub.
4. Click **Add New Project** → Import your repository.
5. Leave settings as default (static site) → **Deploy**.
6. Your site will be live at `https://your-project-name.vercel.app`.

Every future push to the main branch will automatically update the live site.

### Option B — Drag & Drop

1. Go to [vercel.com/new](https://vercel.com/new) or vercel.com/drop.
2. Drag the entire `nathalie-portfolio` folder onto the page.
3. Deploy.

## Customize

- **Photo**: Replace `assets/photo.png` with your preferred photo (square works best).
- **Projects**: Edit the project cards in `index.html`.
- **Colors / fonts**: Adjust CSS variables at the top of `style.css`.
- **Dark mode**: Already included (toggle in the top-right).
